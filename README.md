# Rozpočet CR 📊

Projekt pro správu a analýzu veřejných rozpočtů v České republice.

## Popis

Rozpočet CR je aplikace zaměřená na transparentní přehled a analýzu veřejných rozpočtů České republiky na všech úrovních (státní, regionální, místní).

## Features

- 📈 Analýza veřejných rozpočtů
- 🔍 Hledání a filtrování dat
- 📊 Vizualizace rozpočtů
- 📱 Responzivní design

## Instalace

```bash
# Klonování repozitáře
git clone https://github.com/jakubzavrel/rozpocet-cr.git
cd rozpocet-cr

# Instalace závislostí
npm install

# Spuštění vývoje
npm run dev
```
